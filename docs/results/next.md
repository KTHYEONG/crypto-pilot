# L1/L2 다음 방향성 (2026-07-03 갱신 — L1 비추세 signal admission 후보 확정)

## 1. 확정된 전제 (재검증 불필요, 압축)

- **L1 edge는 100% 시계열 trend-beta, 횡단면 alpha 없음** — XS factor(momentum/carry/flow) 2회 독립 측정으로 승격 0 확정. 재시도 금지. **`xs_oi_skew`는 2026-07-03 실데이터(probe 12심볼) 측정 완료 — "미검증"에서 "약한 부정적 결과"로 하향(아래 참조), 완전 반증은 아님(65심볼 전체 미검증).**
- **L\* 레버리지 옵티마이저가 균일/비례 크기 레버를 전부 흡수** — regime cap, trend-efficiency gate, XS 계열은 byte-identical. **시간분포를 바꾸는 선택적 de-gross(reversal kill-switch)만 구조적으로 L\* 흡수를 피한다는 명제는 여전히 유효**하나(실측 confirmed: variant별 `risk_off_bars` 0→589로 실제 거동이 달라짐), **"그래서 방어에 유효하다"는 함의는 2026-07-02 최초 economic replay에서 반증됨(아래 참조) — L\* 탈출 자체와 경제적 방어력은 별개 문제로 분리해서 취급할 것.** 매그니튜드 레버 추가 탐색 금지(불변).
- **breadth 레벨(cross-sectional downside breadth) 기반 시장상태 판별은 반증됨** — 병목 구간과 평상 구간이 breadth 레벨만으로 구분 안 됨(암호화폐 유니버스 상시 고-breadth baseline). `reversal_mode="panel"`은 opt-in 코드로만 남기고 재시도 금지.
- **reversal kill-switch + recovery cooldown(exit hysteresis) 구현·유닛테스트 완료** — 코드 레벨 동작은 검증됨(entry/exit 신호 분리, 단조 확장, look-ahead 없음, 동적 병목-fold 식별).
- **✅ P0 완료(2026-07-01): "위기 부재 PASS" measure-first 가드레일 구현·감사·라이브 검증 완료.** `docs/specs/l2-promotion-crisis-guardrail.md` 3종 게이트 실装:
  1. **Fold MDD 리포팅 버그 수정** — 이전엔 전 fold MDD가 0.0%로 하드코딩(버그). 이제 실측값 표시(예: 11.6%/17.5%/13.3%).
  2. **Gate A(진단, non-blocking)**: 평가 윈도우에 병목-caliber fold(실측 MDD≥15% ∧ CAGR≤0)가 있는지 스코어카드에 자동 배너로 노출. 강세장 조정(MDD 높지만 CAGR 양수)을 위기로 오인하지 않음(P2 사실상 해소).
  3. **Gate B(blocking, calendar-independent)**: synthetic crash shape("Scenario 8": ATH→지속하락)에 reversal-kill 탐지 로직이 실제로 발화하는지 챔피언 승격 직전 매번 재검증. 미발화 시 챔피언 스토어 갱신 자체를 차단.
  - **라이브 파이프라인 재실행(2026-07-01)으로 3종 전부 실증**: NO-CRISIS-WINDOW 배너가 실제로 스코어카드에 노출됐고, synthetic crash defense는 발화(정상)해 챔피언은 정상 갱신됨. "위기 부재 PASS"가 이제 시스템 화면에 항상 명시적으로 드러나며, 더 이상 사람이 기억에 의존해 조심할 필요가 없음.
- **단, Gate B가 검증하는 것은 "탐지 로직이 죽지 않았다"이지 "실제 크래시를 경제적으로 방어한다"가 아니다.** economic replay로 실제 크래시 방어력을 입증한 적은 여전히 없음 — 관련 평가 윈도우(2024-12-31~2025-12-30)가 기존 병목 구간(24Q4-25Q1)을 벗어나 있어 검증 자체가 불가능한 상태는 그대로다. **P0는 "오인 방지" 문제를 해결한 것이지 "크래시 방어력 실증"(P1) 문제를 해결한 게 아님 — 혼동 금지.**

- **✅ 근본원인 진단 완료(2026-07-02): L1 signal 부족이 아니라 L2 포트폴리오 리스크 모델의 상관관계 무시가 근본원인으로 특정됨.** L3 실제 위기 홀드아웃에서 레버리지를 걷어낸 naive Top-K-EW baseline조차 이미 음수 Sharpe(-0.768~-0.172, run마다 상이하나 항상 음수) — L1이 승격하는 30~50개 신호가 전부 동일 trend-beta factor의 변주라 30~50개 "다양성"이 실제로는 착시. `diagonal_kelly_weights`의 `sigma_port=sqrt(Σwᵢ²σᵢ²)`가 전 포지션 쌍 상관계수 0을 가정 — concentration을 diversification처럼 과소평가. **❌ 반증(같은 날, correlation-aware fix 구현 후 economic replay): correlated 모드(Ledoit-Wolf covariance)로 교정해도 L3 CAGR/Sharpe 개선 없음(diagonal -5.0%/-0.176 vs correlated -5.5%/-0.207, 오히려 소폭 악화).** 원인: L2 champion Leverage L*가 거의 동일(2.0646 vs 2.0481) — `calibrate_deployment_leverage`가 MDD/CVaR 목표치까지 레버리지를 재조정해, correlated 모드의 보수적 sizing을 단일 스칼라로 되돌림. **이미 확정된 "L* 옵티마이저가 균일/비례 크기 레버를 전부 흡수" 사실이 correlation-aware sizing에도 그대로 적용됨을 재확인** — 코드는 정상(단위테스트 5종 PASS)이나 기본값 `"diagonal"` 유지, 프로덕션 전환 보류(opt-in `l2_portfolio_cov_mode`/`L2_PORTFOLIO_COV_MODE` env로 코드는 남김). n=1·reduced trial(50) 비교라 완전 반증은 아님. - **✅ 재검증 완료(2026-07-02, 같은 날 후속): correlated 모드 반증을 full 200-trial·정상 데이터로 재현 — "n=1·reduced trial" 단서 해소, 결론 강화.** 위 반증 직후 이 비교를 재현하려던 실행이 `universe_quality_rejected`로 크래시 — 조사 결과 **본 비교와 무관한 별개의 인프라 결함 2건**을 발견: (1) `sync_single_symbol_data`가 ledger의 `n_zero_volume_bars_60d`를 심볼당 1회만 계산해 전체 동기화 구간(4개월)에 브로드캐스트하는 PIT 위반, (2) live API 경로(`fetch_ohlcv_with_taker`)가 Binance klines의 `quote_asset_volume` 필드를 아예 추출하지 않아 최근 ~32일 데이터가 항상 quote_vol=NaN. 두 결함 모두 수정(코드+테스트) 및 프로덕션 ledger/kline 캐시 실측 복구(529개 심볼, `build_universe` SELECTED 0→150). **수정 후 diagonal/correlated A/B를 reduced trial(50) 대신 full 200-trial로 재실행: CAGR diagonal -5.0% vs correlated -5.6%, Sharpe -0.176 vs -0.214 — 방향 일치, 反證 신뢰도 상향.** correlated 모드는 이제 §3 중단선으로 격상(재시도 시 매번 이 인프라 결함부터 의심하지 않도록). SSOT: `docs/decisions/universe-eh.md`(KLINE-QUOTEVOL/LEDGER-PIT-BROADCAST 항목), `docs/decisions/layer2-eh.md`(2026-07-02 재검증 항목).
- **✅ 계측 인프라 추가(2026-07-02): reversal-kill whipsaw 판별용 episode 단위 계측 배선 완료, 실측은 미실행.** `Layer2FoldAttribution`/`Layer3Result`에 `risk_off_episodes`(entry~exit 타임스탬프+실현손익) 필드 추가, `liquidity_stress_diag.compute_liquidity_stress_discriminative_power`가 half-spread z-score로 true-positive(진짜 방어)/false-positive(whipsaw) episode의 `stress_gap`을 산출하는 순수 함수로 준비됨(p<0.05 이진 게이트 미사용, 방향성+표본수를 사람이 종합판단). **아래 P1①의 half-spread 실측을 이 인프라로 바로 수행 가능한 상태** — 데이터 수집(bookDepth)과 measure-first 사이클만 남음. SSOT: `docs/decisions/layer3-eh.md`(2026-07-02 항목).
- **✅ 완료(2026-07-02~07-03): L1 비추세 signal 다양화 measure-first 전체 사이클 — Admission 통과, ❌ Economic Replay 최종 기각.** "L1이 추세추종에만 편중돼 있다"는 가설 검증 목적으로 pool 확장 실측(Phase 1a) + OI/LSR metrics 물질화(Phase 1b) + admission gate(Phase 2) + seed-matched economic replay(Phase 3) 4단계 전부 완료.
  - **Phase 1a/1b**: `residual_reversion`(beta_neut, 4h 전용→6h/8h/12h 확장) 12심볼·`funding_extreme_reversal`(unwind, 신규 편입) 5심볼에서 LCB>0 승격 — "비추세는 아예 안 통한다"는 우려는 반증(전체 승격의 ~80%가 trend/ts_mom인 편중 자체는 유효). Side 분해로 "bear-regime short 엣지 전무" 가설도 기각. probe 12심볼 metrics 물질화(`track_go=True`) 후 재실측한 OI/LSR 3종(`xs_oi_skew` 등)은 전량 `no_incremental_edge`/표본부족으로 기각.
  - **✅ Phase 2 (admission gate)**: `family_admission.py` 구현·65심볼 A/B 실행 결과 두 후보 모두 admitted=True(trend sleeve corr -0.10/-0.24, 17/9심볼 LCB>0). Regression 1건(`XRPUSDT btc_regime_pullback:12h` 소멸) 발견·원인 규명 — `_compute_incremental_bps`(peer_exclusive)가 동일 (symbol,side,holding_bucket) 내 leave-self-out peer 평균 대비 초과분으로 계산되는 설계라, 신규 family 추가가 기존 pair의 peer 기준선을 이동시켜 부호 반전된 것(버그 아님, 의도된 경쟁 게이트 부작용).
  - **❌ Phase 3 (economic replay) 반증**: seed-matched 3쌍(42/123/7) L1→L2→L3 full run. **3쌍 전부 일관되게 treatment가 baseline보다 악화** — CAGR -11.3~-11.4%→-17.0%, Sharpe -0.86~-0.87→-1.016, MDD 18.8~18.9%→28.0%, Trades 189→57(붕괴). L1 admission(LCB>0, 낮은 trend corr) 통과가 L2 champion 선택 관점에서는 net-negative로 작용 — **"L1 LCB 개선만으로 채택 금지" 원칙이 실증됨.**
  - **최종 결론**: 두 후보 모두 프로덕션 채택 기각. `per_tf_candidate_families` 변경 없음(코드는 실험적으로만 사용). trend-beta 편중 해소 시도가 admission까지는 성공했으나 economic replay에서 막힌 사례 — 다음 시도는 admission gate 자체를 L2 champion 선택 영향까지 반영하도록 강화하거나, P3(구조적 CAGR 상한 재검토) 트리거 후보로 편입 검토. ## 2. 다음 스텝 (우선순위 순)

### P1 — 크래시 방어력 실증 경로 확보 (reversal-kill 반증으로 후보군 재편)
P0 가드레일과 P2 최초 replay 덕분에 "위기 없는 PASS 오인" 문제와 "reversal-kill이 실제로 방어하는가" 질문 둘 다 이제 명시적으로 답변 가능한 상태다. **reversal-kill(entry/exit 튜닝만으로는)은 1차 시도에서 반증됐으므로, 다음은 detection 입력 자체를 바꾸는 방향이 우선순위가 높아졌다.**
- **① 마이크로구조 데이터 확장 — OI/LSR/funding 축은 5라운드 실측 후 보류로 재분류(2026-07-02).** bookDepth / half-spread / liquidation proxy / funding-OI stress 등을 BTC~7개 대형심볼로 실측(위 §1 참조): breadth·장기추세는 반증, funding×OI 결합만 방향성 있으나 p=0.285로 유의성 미달(n=45/15, 독립 위기국면 1회의 검정력 한계). **재시도하려면 (a) 새 독립 위기 국면 재유입 시 표본 확장 재검정, 또는 (b) bookDepth/half-spread(아직 미측정, 유일한 미탐색 후보)로 완전히 다른 입력을 시도할 것** — 동일 OI/LSR/funding 조합 반복 탐색은 다중검정 위험 증가로 비권장. **계측 인프라는 준비 완료(2026-07-02, 위 §1 참조)** — `run_l3_reversal_economic_replay`의 `risk_off_episodes` + `compute_liquidity_stress_discriminative_power`로 half-spread 판별력을 즉시 측정 가능. 남은 작업은 (i) BTCUSDT bookDepth 실데이터 수집(`fetch_bookdepth_daily`, 이미 구현됨), (ii) 대표 variant 1개에만 검정 적용(다중검정 방지), (iii) `stress_gap` 방향성으로 채택/보류 판단(p<0.05 단독 게이트 금지).
- **② RC-2 fit-MDD crisis gate**: ✅ 구현 완료(위 §1 참조, 기본 비활성). **레버리지 계산 결함은 고쳤지만 이번 replay는 그 결함과 무관하게 reversal-kill 메커니즘 자체가 이 위기에서 무력했음을 보였다** — 이 항목은 "완료됐지만 P1의 핵심 문제를 해결한 게 아님"으로 재분류. `fit_mdd_crisis_gate` 자체의 economic replay 스윕(0.88/0.90/0.92 후보)은 여전히 별도 미완료 작업(`docs/decisions/layer2-eh.md` 참조).
- **③ horizon 확장**: 일/주 단위 regime·macro state를 조건화해, 4h~12h 단일 스케일 detector가 놓치는 구조적 위기 신호(유동성 위축, 매크로 리스크오프) 포착. reversal-kill의 whipsaw 문제(짧은 스케일 detector가 회복 랠리를 위기로 오인)를 완화할 수 있는 후보로 ①과 함께 재검토.
- **④ (신규) dd_threshold/persistence_bars/cooldown 파라미터 재튜닝은 중단선으로 이동(§3 참조)** — 이번 replay가 커버한 8종이 전부 실패했으므로 같은 파라미터 공간 재탐색은 금지, 입력 자체(①③)를 바꾸는 게 우선.
- **판단 기준**: 새 입력을 추가하기 전 반드시 measure-first(H1 가설 → 계측 → 반증/채택) 절차를 거칠 것 — breadth 레벨 반증, reversal-kill 반증 사례처럼 그럴듯한 가설도 실측 전엔 신뢰하지 말 것.
- **Gate B를 이 작업의 회귀 방지망으로 재사용**: 새 크래시 방어 로직을 추가할 때마다 `synthetic_crash_defense_verdict` 패턴을 확장(다양한 synthetic 위기 형태 — flash crash, 완만한 약세장, 유동성 위축 시뮬레이션 등)해 "여전히 발화하는가"를 계속 자동 검증할 것. **단, 이번 반증이 보여주듯 Gate B 통과는 경제적 효과의 증거가 아니므로, 새 detection 입력도 반드시 `run_l3_reversal_economic_replay`류의 실제 holdout replay로 검증할 것.**

### P2 — 실제 위기 구간 재유입 시점의 economic replay 확보
**✅ 완료(2026-07-02): 최초 실행 및 반증.** 평가 윈도우가 롤링되며 실제 위기 구간(2025-12-31~2026-06-30, BTC -32.8%)이 L3 홀드아웃에 진입했고, Gate A NO-CRISIS-WINDOW 배너가 예고한 그 "기회"를 `run_l3_reversal_economic_replay`(신규 인프라)로 실제 실행 — 결과는 reversal-kill 반증(§1 참조). 이 절차(배너 소멸 감지 → replay 실행 → variant별 defense 성과 비교) 자체는 이제 재사용 가능한 표준 경로로 확립됨 — P1에서 새 방어 로직(①③)이 나오면 동일 절차로 재검증할 것. 평가 윈도우가 다시 롤링되어 새로운/추가 위기 구간이 들어올 때마다 반복 실행 권장(저강도 모니터링 성격 유지).

### P3 — 목표 재검토 (P1 반복 실패 시)
- trend-beta가 유일한 edge이고 reversal-kill은 신규 alpha가 아니라 방어 레버일 뿐이라는 점을 감안, P1이 반복 실패하면 **현재 strategy class의 구조적 CAGR 상한을 재평가**할 것 — 목표(예: 30%)가 현재 아키텍처로 달성 불가능한 수준인지 정직하게 재검토. **reversal-kill 1차 반증(2026-07-02)으로 이 트리거에 한 걸음 가까워짐 — ①③(마이크로구조/horizon) 시도까지 반복 실패할 경우 P3 재평가를 실제로 진행할 것.**

### P4 — ✅ 완료·기각(2026-07-03): L1 비추세 signal admission gate + economic replay
전체 4단계(Phase 1a/1b/2/3) 완료, 최종 결과는 위 §1 참조. 두 후보(`residual_reversion`/`funding_extreme_reversal`) admission gate 통과에도 불구하고 economic replay에서 seed-matched 3쌍 전부 악화 — 프로덕션 채택 기각. 재시도 시 admission gate 자체를 L2 champion 선택 영향까지 반영하도록 재설계하지 않는 한 동일 결론 반복 예상(§3 중단선 참조).

## 3. 명시적 중단선

- **Correlation-aware 포트폴리오 sizing(`l2_portfolio_cov_mode="correlated"`) — 2026-07-02 full-trial 재검증까지 완료, 재시도 금지.** n=1·reduced trial 단서가 해소된 채로도 diagonal 대비 CAGR/Sharpe/Sortino 전부 악화, L*가 correlated의 보수적 sizing을 흡수(2.0646 vs 2.0477, 거의 동일)하는 메커니즘 재확인. 코드는 opt-in으로 유지하되 프로덕션 채택 재시도 금지 — L* 계산 자체를 correlation-aware하게 재설계하는 것만 미검증 후속 후보(별도 아키텍처 변경 필요).
- XS cross-sectional factor, regime cap, trend-efficiency gate, breadth 레벨 판별(가격 기반) — **전부 반증 완료, 재시도 금지**.
- **OI/LSR/funding 기반 crash-detection 후보(단일심볼 z-score, 1일 변화율, 14일 장기추세, 멀티심볼 breadth) — 2026-07-02 5라운드 실측으로 전부 반증 또는 유의성 미달(재시도 금지, `docs/decisions/layer3-eh.md` 참조).** 특히 OI/funding breadth는 위 가격기반 breadth와 동일한 실패 패턴(calm 구간 최대치가 crisis보다 높음) 재확인. 유일한 예외: funding×OI 3일 결합(절대 threshold)은 완전 반증은 아니며(p=0.285, 방향성 있음) 신규 독립 위기 국면 유입 시 표본 확장 재검정 가치 있음 — 단, 동일 표본으로 재탐색(파라미터만 바꾸는 재시도)은 금지.
- **"위기 없는 윈도우에서의 PASS"를 프로덕션 승격 근거로 인용하는 것 — P0 가드레일(Gate A 배너 + Gate B 하드 게이트)로 구조적으로 방지됨. 더 이상 별도 수동 체크 불필요.**
